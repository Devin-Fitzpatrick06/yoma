  - `seed/fetch-live-catalogue.mjs --tasks` writes `.cache/live-tasks.json`. 41 live tasks on 27 Nov, 3 of them from
    IXO. `--max` works as before.
  - New `seed/generate-tasks-sql.mjs`, modelled on the job importer. Organisations, categories by live id (with the two
    merges), countries, languages, skills by name (missing skills added under their live ids), verification types, Zlto
    and commitment. The live difficulty goes into the `ImpactActionDifficulty` custom field, with the migration's
    mapping. IXO tasks get a partner sync record. Duplicates are skipped (`ON CONFLICT`), and the custom-field and
    relation rows only go to newly inserted tasks.
  - `seed/assess-live.mjs --tasks` runs Ziqi's listing checks on them, with its own progress file and `--no-grade`.
  - In `start.sh`, a new block before the jobs, as for jobs: it runs only when the database has no `ImpactAction`
    listings, so an older saved database gets them too. The database is saved again afterwards (after the jobs save,
    or on its own when the jobs were already there).
- **Synthetic "usually go on to" chains** (W4), in the same generator. Per demo goal (`Pathway:Goals` read from the
  API's `appsettings.json`, mounted at `/appsettings.json` in the runner):
  - A is the most-completed course of the goal's stages (not the last). B is the impact action most plausibly linked
    to it (stage pattern, then shared skills, then category; each goal prefers its own). C is a course of the next
    stage, preferring shared skills or category.
  - 24 of A's demo completers complete B 6 to 12 days ago, and 16 of those complete C 2 to 5 days later.
  - Only completions are added, never a start without one, so no drop-off is implied. Each row's `CommentVerification`
    starts "Demo data: a synthetic pathway completion". The generator adds the chains once.
  - The patterns use `\y` for .NET `\b`. Details are in README "Synthetic pathway completions".
- **start.sh summary**: separate counts for courses, impact actions and jobs, the synthetic completion count, and the
  six Ziqi links (My Yoma, YoID, partner create listing, journey map preview, Ziqi draft preview, Ziqi admin preview),

## Gotchas

- Chains depend on the existing demo participation, which comes from live counts. A refreshed catalogue can pick other
  A/B/C listings, and a goal with no course of 21+ demo completers older than 45 days gets no chain (a NOTICE says so).
- Recent popular live courses (for example "Prevention of Sexual Exploitation and Abuse", start 3 Nov) collect many
  recent demo completions. That is why B and C are dated in the last two weeks.
- The course import still does not set `LearningDifficulty` (the pathway catalogue reads it), though the live search
  returns `difficulty`. That is out of this ticket; it would be a small addition to `generate-sql.mjs`.
- The public search returns `customFields`, but they were empty for all 41 tasks fetched.
- With `--sample`, impact actions are still added and checked, but nothing is saved, as before.
