## Built

- API: assessment engine, link checker, keyless source-page reader, optional Anthropic provider,
  `CourseQuality.Assessment` table, migration `20261102050551_ApplicationDb_CourseQuality_Assessment`,
  controller, background job (off by default).
- Web: learner card on the opportunity page, reviewer queue, partner fix notes, coverage summary,
  development-only preview at `/course-quality-preview`.
- Demo: `scripts/course-quality-demo/` starts everything in Docker with one command. It uses
  demo-only settings, including a closed fixture network. Never copy those to a deployed
  environment.

## Blocks production

- Cost still needs a person or trusted domain behind it, because text parsing is best effort.
- Text hidden by CSS is not detected.
- A live Claude check of token limits and schema.

  "X - Free Online Course" do not exactly match a listing, so those decisions lapse weekly.

- The reader is English-only.
- Only Alison can be self-paced, through `CourseQuality:SelfPacedProviders`. Other providers rely
  on reviewers.
