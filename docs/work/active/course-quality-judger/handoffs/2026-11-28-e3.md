## What Was Done

Built against the "Iteration 5" contract in `src/web/src/api/models/courseQuality.ts`, using fixtures only. The API (E1, E2) was built in parallel, so nothing here has run against a live endpoint yet.

- **Services**
  - `api/services/courseQualityAI.ts`:
    - `getCourseQualityAIUsage` calls `GET /courseQuality/ai/usage`.
    - `runCourseQualityAICheck` calls `POST /courseQuality/opportunity/{id}/assess` with a 10-minute axios timeout, so the client's 45 s abort does not cut off a local model.
    - `AI_USAGE_QUERY_KEY` is `["courseQuality","ai","usage"]`.
  - `api/services/linkHealth.ts`: `checkLinkHealth` calls `POST /courseQuality/links/check`, also with a 10-minute timeout.
- **Reviewer card** (`pages/admin/course-quality/review.tsx`). A new "AI check" section (`components/CourseQuality/AIUsageCheck.tsx`) sits under Checks. It replaces the old Evidence-summary block and the "Page reader / Rules only" note.
  - It shows the AI's summary and the run line, e.g. "Local model · qwen2.5:3b on localhost:11434 · 3,214 in / 412 out tokens · $0.00 (local, free) · 42 s · Answered".
  - It shows a Local · free or Remote · billed badge, an outcome chip and the outcome in plain words.
  - When `aiUsage` is null it says "No AI ran for this check (rule-based reader)". For an assessment from before iteration 5 that ran an AI, it says so without usage figures.
  - **Run AI check** shows a pending state: the elapsed seconds, the configured model (from the usage endpoint) and an aria-live status. The returned assessment replaces the card in place: a `refreshed` map is keyed by the batch item id, so outcomes, skip and decisions stay keyed by the batch. Decisions go to the id of the assessment on screen.
- **Admin AI usage panel** (`components/CourseQuality/AIUsagePanel.tsx`), on `/admin/course-quality` under Coverage:
  - the provider, model and host, the local or remote badge, and Configured or Not configured (with the settings to set);
  - totals: runs, answered, tokens in and out, total cost, average time;
  - a recent-runs table that scrolls inside its own region on narrow screens, and an empty state.
  - The header also gains a "Link health" link.
- **Link health page** `/admin/course-quality/links` (Admin SSR guard). It uses:
  - `LinkHealthChecker`:
    - paste a list, or upload a .txt/.csv of up to 5 MB, parsed in the browser (delimiter detection and a link-column picker);
    - an optional platform label;
    - batches of 200 checked one after another, with progress and a "Stop after this batch" button;
  - `LinkHealthResults`: status counts that act as filters (`aria-pressed`), chips with colour and text, "Show more" after 100 rows, and a client-side Blob "Download CSV";
  - `LinkHealthGuide`: what each status means (Blocked and Refused explained), plus a mention of `scripts/link-health/check-links.mjs`.
- **Preview** `/ziqi-admin-preview` has three new sections:
  - four AI-check states, including a runnable fake check that takes 4 s;
  - three AI-usage panels: with runs, empty, and not configured;
  - the link checker with a fake checker that fetches nothing, plus the guide.
- **Tests**:
  - `AIUsage.helpers.test.ts`: formatting tokens, cost and duration, the run line, outcome wording.
  - `LinkHealth.helpers.test.ts`: list and CSV parsing, link-column detection, batching, counts and merging, CSV export (including formula-injection quoting), the file name.

## Gotchas

- **The axios slow-network toast** ("taking longer than usual") still fires after 10 s on the AI check and the link check. `lib/axiosClient.ts` only exempts CSV uploads from it, and that file is outside E3's area. Request: add `/courseQuality/opportunity/*/assess` and `/courseQuality/links/check` to its long-request list.
- **The old `assessCourseQuality`** in `courseQualityAdmin.ts` keeps the 45 s timeout. Use `runCourseQualityAICheck` for AI runs.
- **A re-assess can return a new assessment id and status**, for example when the AI lowers a result to Not verified. A decision then goes to the new id. If the API rejects it because the assessment is no longer Pending, the error toast shows.
- **The recent-runs title** links to the public `/opportunities/{id}` page, because `CourseQualityAIRun` has no organisation id.
