## Built

All in `src/web/src/components/MyYoma/JourneyMap/` (`types.ts` untouched), plus a `view=map` case in
`src/web/src/pages/my-yoma-preview.tsx`.

- `JourneyMap.tsx` (default export, implements `JourneyMapProps` exactly): Start (YoID: `startLabel`, name,
  completions, credentials, skills) → per stage a header (Learn / Practise / Prove kicker, name, why, "x of y done"
  or "Stage complete", "Shortened" tag) and its steps → First job (`destinationLabel` + job links). Vertical list on
  phones; from `lg` a horizontal `snap-x` track in a scroll region (focusable, ← → buttons).
- Trail: an SVG quadratic path through every station's dot, measured after layout (`useLayoutEffect` +
  `ResizeObserver`), so it fits both orientations and any card height. `stroke-dashoffset` draws it on entrance;
  a green "done" trail runs to "You are here" and transitions when it moves. The marker is a pulsing ring on the
  trail at the first unfinished step (destination when all done), with a "You are here" pill on desktop and chip on
  the card; it slides along the trail when a step completes.
- Entrance (`animateEntrance`): stations fly in one by one (160 ms stagger), each dot snaps with a ring, and a small
  padlock clicks shut on it (stays for locked steps, fades for the rest). Without `animateEntrance`, everything
  renders in place and the desktop track starts scrolled to "You are here".
- `StepCard.tsx`: type icon + label, Done / You are here / In progress / Locked chips, title link covering the card
  (opens `/opportunities/{id}`, calls `onStepEvent(id, "Started")`), provider + partner badge (Bronze–Platinum;
  Platinum has a sheen; None/NotEnoughGraded hidden), `GradeChip` with `gradeLabel`, hours, skills added, reason,
  "Young people who completed this usually go on to …" with % and n (top 2, only when non-empty, "Demo data:
  synthetic learners" in the demo build), the reserved drop-off slot (always rendered, text from `dropOff.note`,
  never a number), Lock (`aria-pressed`, optimistic, error inline) and Swap.
- `SwapSheet.tsx`: portal modal — bottom sheet on phones, pop-over from `sm`; `loadAlternatives` with skeletons,
  error + retry, empty state; up to 3 alternatives slide in; picking calls `onSwap`, the pick pulses, the sheet
  closes, the new card flips into place and receives focus. Focus trap, Escape, backdrop close, focus returns to
  the Swap button, body scroll locked.
- "Shown": one `IntersectionObserver` (threshold 0.5), once per opportunity id per mount.
- Celebration: `celebrationsBetween(prev, next)` across renders → confetti burst at the step dot and a bigger one at
  the stage dot, dot "cheer", and an `aria-live` announcement. Not on first render or for swapped-in steps.
- Motion: keyframes in `JourneyMap.module.css` (transform/opacity only; CSS module like `Status/Loading.module.css`,
  since Tailwind's theme has none of these). `prefers-reduced-motion` switches every animation off, and confetti is
  not rendered at all. No new dependencies; Yoma tokens and Nunito via Tailwind.
- Pure helpers `journeyMap.ts` (ordering, you-are-here index, stage completion, celebrations, stage kind, partner
  badge visibility, next steps, hours, drop-off line, trail path and fraction) with `journeyMap.test.ts`.
- Fixtures `journeyMap.fixtures.ts`: the shared My Yoma fixture with an impact action and a task stage, a locked
  step, a completed stage, an in-progress step, `usuallyNext` on four steps, Platinum/Gold/Silver/Bronze badges,
  alternatives and lock/swap/complete helpers.
- Preview `/my-yoma-preview?view=map`: "Replay entrance", "Complete next step" (shows the celebration), last step
  event; lock/swap/alternatives act on local state with short fake delays.

## Decisions (for the lead)

- Clicking a **completed** step does not send `Started` (would pollute drop-off data); everything else does.
- Swap is hidden on completed steps and disabled on locked ones ("Unlock this step to swap it"). The map does not
  send `Swapped` itself: assumed the swap endpoint records it (W5/A4) — add `onStepEvent(id, "Swapped")` in the
  page if not.
- The drop-off slot shows `dropOff.note`, prefixed "Drop-off:" unless the note already starts with it; the rate is
  never rendered, even when `Available`.
- Stage kicker: Practise when a stage holds an impact action/task, Prove for the last stage of a 3+ stage path,
  Learn otherwise (no contract field for this).
