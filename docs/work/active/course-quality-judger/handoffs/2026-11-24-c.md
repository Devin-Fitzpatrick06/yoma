## Gotchas

- The demo runs no background batch, so events and jobs are assessed only through `POST courseQuality/opportunity/{id}/assess`;
  the demo database holds Learning listings only.
- `VerifyTypes` is a list: configuration binding appends to the default, so Learning cannot be configured off (on purpose).
- `CourseQualityAIRequest` gained `Type` (default Learning). The Anthropic provider ignores it and still uses the course prompt;
  if it is switched on for events or jobs, its format and self-paced answers are ignored by the engine, but its prompt should
  be checked.
- Event and job fix notes appear on the partner's course-quality page and in the review queue alongside courses.
- Action-link completions are recognised by their fixed verification comment only (see `../badges.md`).
